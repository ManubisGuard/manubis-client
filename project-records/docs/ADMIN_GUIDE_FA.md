# راهنمای پنل مدیریت فروشگاه ManubisGuard

## آدرس‌ها

- داشبورد مدیر: `https://all.qoqnusradio.top/store-api/admin`
- Base URL فروشگاه برای اپ: `https://all.qoqnusradio.top/store-api`
- API عمومی کاتالوگ: `/api/v1/store/plans`
- API عمومی تنظیمات نمایشی: `/api/v1/store/settings`

## نقش مدیر و اپلیکیشن یکسان نیست

داشبورد وب یک ابزار جداگانه برای مدیر اصلی است. اپلیکیشن هرگز `ADMIN_API_TOKEN`، کلید API پنل اصلی یا اعتبارنامه مدیر را دریافت نمی‌کند. اپ فقط Base URL عمومی Store API را می‌شناسد و اطلاعات عمومی فروشگاه و پلن‌های فعال را می‌خواند. تمام تغییرات مدیر در Backend و دیتابیس ذخیره می‌شوند؛ پس از refresh یا درخواست بعدی اپ، تنظیمات و پلن‌های به‌روز را می‌گیرد.

## ورود مدیر

1. آدرس داشبورد بالا را در مرورگر باز کنید.
2. مقدار `ADMIN_API_TOKEN` را از secret manager یا محیط امن سرور دریافت کنید و در فیلد ورود مدیر قرار دهید.
3. توکن را در پیام، سورس، APK، screenshot یا `todo.md` قرار ندهید. داشبورد آن را فقط در `sessionStorage` همان نشست مرورگر نگه می‌دارد؛ با خروج یا پایان نشست آن را پاک کنید.
4. اگر مقدار فعلی فقط placeholder است یا نامطمئن است، یک توکن تصادفی قوی بسازید و از طریق محیط امن سرویس تنظیم کنید؛ توکن را داخل Android قرار ندهید.

## افزودن پلن

1. بخش «قالب‌ها» را باز کنید و قالب‌های پنل را بارگذاری کنید.
2. در فرم «ایجاد پلن» شناسه یکتا، نام، توضیحات، قیمت، ارز، مدت بر حسب ثانیه، حجم بر حسب بایت و قالب پنل را مشخص کنید.
3. پلن را فعال و ذخیره کنید؛ سپس فهرست پلن‌ها را تازه‌سازی کنید.
4. فقط پلن فعال در کاتالوگ عمومی اپ نمایش داده می‌شود.

مهم: این مرحله فقط کاتالوگ را تنظیم می‌کند. تا زمانی که provisioning و نگاشت واقعی به API پنل تکمیل و تست نشده، ایجاد پلن به‌تنهایی به معنی امکان ساخت خودکار اشتراک مشتری نیست.

## تنظیمات فروشگاه و کارت‌به‌کارت

در «تنظیمات عمومی فروشگاه» نام، توضیحات، ارز، لینک پشتیبانی و حالت تعمیرات را تنظیم کنید. برای کارت‌به‌کارت، نام صاحب کارت، شماره کارت، نام بانک و راهنمای پرداخت را وارد و کلید پرداخت را فعال کنید. قبل از فعال‌سازی برای مشتریان، سفارش آزمایشی و مسیر بررسی رسید را تست کنید. در محیط فعلی کارت‌به‌کارت پیش‌فرض خاموش است و اطلاعات کارت خالی است.

## اتصال به پنل اصلی

در «تنظیمات اتصال پنل»، Base URL و کلید API پنل را وارد کنید. کلید فقط در Backend ذخیره می‌شود و با رمزنگاری Fernet محافظت می‌شود؛ کلید رمزنگاری `PANEL_SETTINGS_ENCRYPTION_KEY` باید پایدار و محرمانه نگهداری و backup امن شود. اگر کلید API در فیلد خالی باشد، کلید ذخیره‌شده عوض نمی‌شود. ابتدا اتصال را تست کنید و مطمئن شوید کلید دارای حداقل مجوز لازم برای محیط آزمایشی است.

## وضعیت تکمیل و محدودیت‌ها

- داشبورد، تنظیمات فروشگاه، CRUD پلن‌ها، تنظیم اتصال پنل و بررسی رسید کارت‌به‌کارت پیاده‌سازی شده‌اند.
- اپ از `https://all.qoqnusradio.top/store-api` استفاده می‌کند و نباید توکن مدیر را داشته باشد.
- آدرس داشبورد از مسیر HTTPS منتشر شده و API مدیریتی بدون Bearer token باید `401` بدهد.
- فعال‌سازی/تمدید واقعی اشتراک بعد از تأیید پرداخت، حساب مشتری، نگاشت کامل پلن به پنل، audit log و تست end-to-end هنوز نیازمند تکمیل و اعتبارسنجی هستند. تأیید رسید فعلاً وضعیت را به `paid_pending_provisioning` تغییر می‌دهد و اشتراک را خودکار نمی‌سازد.
- پیش از استفاده عملیاتی، HTTPS، محدودسازی نرخ درخواست‌های مدیریتی، نگهداری امن secretها، backup/restore و دسترسی staging باید بازبینی شوند.


### قفل داشبورد قبل از ورود
صفحه مدیریت در ابتدا فقط فرم ورود را نمایش می‌دهد. بخش‌های مدیریتی پس از ارسال توکن مدیر و تأیید موفق آن توسط API باز می‌شوند. در صورت توکن نامعتبر یا خروج، داشبورد دوباره مخفی و توکن نشست پاک می‌شود. این قفل نمایشی مکمل کنترل دسترسی سمت سرور است؛ همه APIهای مدیریتی نیز مستقل از رابط کاربری توکن را بررسی می‌کنند. در نسخه فعلی ورود با توکن مشترک مدیر انجام می‌شود و هنوز حساب‌های جداگانه، نقش‌ها یا MFA وجود ندارد.
